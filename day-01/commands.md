# Day 1 - Linux CLI Commands

| Command | Fungsi |
|---|---|
| `pwd` | Menampilkan lokasi directory saat ini. |
| `ls` | Menampilkan isi directory. |
| `cd` | Berpindah directory. |
| `mkdir` | Membuat directory baru. |
| `touch` | Membuat file kosong atau memperbarui timestamp file. |
| `echo` | Menampilkan teks atau mengirim teks ke file. |
| `vim` | Membuat atau mengedit file melalui terminal. |
| `cp` | Menyalin file atau directory. |
| `mv` | Memindahkan atau mengganti nama file/directory. |
| `rm` | Menghapus file atau directory. |

## Vim Basic

| Command/Key | Fungsi |
|---|---|
| `i` | Masuk Insert Mode. |
| `Esc` | Kembali ke Normal Mode. |
| `:w` | Menyimpan file. |
| `:q` | Keluar dari Vim. |
| `:wq` | Menyimpan dan keluar dari Vim. |
