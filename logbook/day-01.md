# Day 1 - Linux CLI Fundamentals

## Objective

Memahami command dasar Linux dan membiasakan diri bekerja melalui terminal.

- WSL Ubuntu
- Bash
- Vim
- Git
- GitHub

## Commands Learned

4. mkdir
5. touch
6. echo

9. mv
10. rm

## Practice

Membuat directory `day-01`, membuat dan mengedit file `notes.txt`,
menyalin file, mengganti nama file, dan menghapus file hasil latihan.

## Vim Practice

- `i` → Insert Mode
- `Esc` → kembali ke Normal Mode
- `:w` → save
- `:q` → quit
