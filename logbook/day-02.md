# Day 2 - Linux Filesystem & File Operations

## Objective

Memahami filesystem Linux dan mempelajari command untuk melihat,
mencari, memeriksa, dan membaca file serta directory.

## Environment

- WSL Ubuntu
- Bash
- Vim
- Git
- GitHub

## Commands Learned

1. tree
2. find
3. file
4. stat
5. du
6. df
7. cat
8. less
9. head
10. tail
11. wc

## Practice

Mempelajari struktur directory menggunakan `tree`.

Mencari file dan directory menggunakan `find`.

Memeriksa tipe file menggunakan `file`.

Melihat informasi detail file menggunakan `stat`.

Mempelajari penggunaan disk menggunakan `du` dan penggunaan
filesystem menggunakan `df`.

Membaca isi file menggunakan `cat` dan `less`.

Mempelajari cara melihat bagian awal dan akhir file menggunakan
`head` dan `tail`.

Mempelajari cara menghitung jumlah baris, kata, dan karakter
menggunakan `wc`.

## Filesystem Practice

- Melihat struktur repository
- Mencari file dan directory
- Memeriksa tipe file
- Melihat metadata file
- Memeriksa penggunaan disk
- Membaca isi file

## Result

Berhasil mempelajari command dasar untuk melakukan inspeksi
filesystem Linux dan membaca informasi dari file.
