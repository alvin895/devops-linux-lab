# Day 2 - Linux Filesystem & File Operations

## Commands Learned

| Command | Fungsi |
|---|---|
| `tree` | Menampilkan struktur directory dalam bentuk tree. |
| `find` | Mencari file dan directory berdasarkan kondisi tertentu. |
| `file` | Menampilkan tipe atau jenis file. |
| `stat` | Menampilkan informasi detail file atau directory. |
| `du` | Menampilkan penggunaan disk oleh file atau directory. |
| `df` | Menampilkan penggunaan filesystem/disk. |
| `cat` | Menampilkan isi file. |
| `less` | Membaca isi file halaman demi halaman. |
| `head` | Menampilkan bagian awal file. |
| `tail` | Menampilkan bagian akhir file. |
| `wc` | Menghitung jumlah baris, kata, dan karakter. |
