# Day 3 - Linux Users & Permissions

## Commands Learned

| Command | Fungsi |
|---|---|
| `whoami` | Menampilkan nama pengguna yang sedang aktif. |
| `id` | Menampilkan UID, GID, dan grup pengguna. |
| `groups` | Menampilkan grup yang diikuti pengguna. |
| `ls -l` | Menampilkan daftar file beserta permission, owner, dan group. |
| `chmod` | Mengubah permission file atau directory. |
| `chown` | Mengubah owner file atau directory. |
| `chgrp` | Mengubah group file atau directory. |
| `umask` | Menampilkan atau mengatur mask permission default untuk file baru. |
| `sudo` | Menjalankan perintah dengan hak pengguna lain, jika diizinkan. |
| `su` | Berpindah ke akun pengguna lain. |
